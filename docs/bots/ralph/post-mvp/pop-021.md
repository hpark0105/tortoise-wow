# POP-021: Qualify fifty active bots

- Epic: KAP-543
- Depends on: POP-020
- Status: blocked by dependency

```gherkin
Scenario: Sustain the first scaled cohort
Given 50 valid persistent bots and a recorded zero-bot baseline
When bots activate at a bounded rate and run for thirty minutes
Then 50 achieved sessions, regional actions and saves are observed
And world processing, memory, database writes and failures are reported

Scenario: Report lower achieved capacity
Given login failures or a resource threshold breach
When the stage cannot sustain 50 active bots
Then activation backs off
And the run fails with the achieved count and limiting measurement
```

Extend the ten-bot observer rather than creating a second measurement format.
Record the exact commit, image, hardware, scenario seed, requested/achieved
counts and configuration. Use paced activation and a disposable project. Do
not count database rows, parked identities or synthetic protocol clients as
active gameplay sessions.
