# LLM-010: Bounded local party-planner transport

- Epic: KAP-543
- Depends on: CMP-012, CMP-013, CMP-014
- Related: `../mvp/llm-001-park-llama-concurrency.md`
- Status: blocked by dependency

```gherkin
Scenario: Accept one current bounded party plan
Given a versioned immutable party observation and available park-llama service
When one shared request returns before its deadline
Then schema-valid allowlisted steps with matching party, goal and observation
versions are offered to the deterministic controller

Scenario: Continue without the model
Given the model is busy, offline, slow, malformed or returns a stale plan
When the planner request fails validation
Then no action from it executes
And deterministic follow, combat and recovery continue
```

Use one shared party request rather than one model call per companion. The
transport must not block the world thread or send live object pointers, broad
logs, credentials, arbitrary commands or SQL.
