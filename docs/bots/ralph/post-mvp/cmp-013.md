# CMP-013: Minimal healer triage policy

- Epic: KAP-543
- Depends on: PORT-015
- Status: hosted roll-up; implementation is companion-port/PORT-015

Do not dispatch this card as a second implementation assignment. Preserve it as
the original KAP-543 acceptance summary for [PORT-015](../companion-port/port-015.md).

```gherkin
Scenario: Heal a declared small pull
Given a supported healer class in the owner's party
When party health falls during combat
Then the healer prioritizes survival using learned legal spells
And preserves enough range, line of sight and mana to continue the pull

Scenario: Recover before the next pull
Given low mana, no legal heal or an unreachable party member
When the healer evaluates party readiness
Then the party waits or reports the blocker instead of starting another pull
```

Start with one class and explicit heal thresholds. Prove spell legality,
target choice, resource use and recovery without hidden regeneration or buffs.
