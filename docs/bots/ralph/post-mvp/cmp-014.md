# CMP-014: Damage assist and pull discipline

- Epic: KAP-543
- Depends on: CMP-011, CMP-012
- Status: blocked by dependency

```gherkin
Scenario: Assist the party tank
Given a supported damage class and an established tank target
When the damage companion enters combat
Then it assists that target using learned legal attacks
And does not pull an unselected nearby enemy

Scenario: Preserve crowd control and stop authority
Given a controlled target or an owner stop command
When an offensive action is considered
Then the companion does not damage the controlled target
And no invalidated action resumes after stop
```

Start with one ranged or melee damage class. Add further classes as separate
cards after the shared policy passes.
