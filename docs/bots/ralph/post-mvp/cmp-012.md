# CMP-012: Minimal tank threat policy

- Epic: KAP-543
- Depends on: CMP-011
- Status: blocked by dependency

```gherkin
Scenario: Tank a declared small pull
Given a supported tank class with learned legal abilities and normal gear
When the party starts a declared two-creature pull
Then the tank establishes threat before damage companions engage
And taunts or changes target when a non-tank party member holds threat

Scenario: Avoid an unsafe pull
Given no healer resources, an uncontrolled extra target, or an unreachable
enemy
When the tank evaluates the pull
Then it waits, recovers, or stops with a bounded reason
```

Start with one class and a declared level/spell matrix. Measure threat through
normal server state. Do not grant spells, stats or threat to pass the test.
