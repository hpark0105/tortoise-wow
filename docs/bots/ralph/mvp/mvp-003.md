# MVP-003: Prevent autonomous attacks on players and friendly units

Implementation boundary: the core target selector already filters to hostile
units. This slice adds the final guard at idle acquisition, so a hostile player
is never selected for an autonomous opening attack. Existing combat victims are
left to the combat branch so a bot can defend itself.
With `PlayerBot.Debug=1`, skipped player targets emit a bounded diagnostic line
for a future runtime fixture; the diagnostic is disabled by default.
